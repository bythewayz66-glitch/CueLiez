# Training Media (GUI)

Place optional local media files here for the CueLiez Training GUI. The GUI works without media and shows an honest "no media file provided" message when files are absent.

Supported (rendered when present):
- `gov/overview.png`, `gov/workflow.png`, `gov/intro.mp4` or `gov/intro.webm`
- `leg/overview.png`, `leg/workflow.png`, `leg/intro.mp4` or `leg/intro.webm`
- `med/overview.png`, `med/workflow.png`, `med/intro.mp4` or `med/intro.webm`
- `thrp/overview.png`, `thrp/workflow.png`, `thrp/intro.mp4` or `thrp/intro.webm`

Do not add media that implies lie detection, deception verdicts, diagnoses, or other prohibited claims. Observation/cue-only training framing applies.
