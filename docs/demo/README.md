# CueLiez Demo Materials (Presenter)

These materials prepare **you** to demo CueLiez safely and accurately.

CueLiez is a **Legal Interview Engine** (Cue + **L**egal **I**nterview **E**ngine). It provides real-time **observation and cue** support for human-led interviews. It is **not** a lie detector, not a polygraph, and not a truth machine.

## Non-negotiables

- Never call CueLiez a **lie detector**, **truth detector**, or **polygraph** (or substitute).
- Never claim it **detects lies**, **confirms deception**, or determines who is **lying/truthful/guilty/innocent**.
- Present outputs as **probabilistic observations/cues for professional human review**.
- In demos involving realistic data, use synthetic/sample transcripts or properly consented/authorized examples. Follow applicable law, policy, and ethics.
- Show gates/consent/training/dual-control where relevant — they are part of the product, not optional.
