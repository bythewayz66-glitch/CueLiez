# CueLiez Language Rules

**Status:** Mandatory for all product copy, docs, UI, sales, investor materials, and code comments that ship with CueLiez.

## Name

- **Product name:** CueLiez
- **Expansion (required on first use in a document):** Cue + **L**egal **I**nterview **E**ngine
- Do not expand LIE as "lie" in the sense of untruth.

## Forbidden phrases

Do **not** use any of the following in connection with CueLiez:

| Forbidden | Why |
|-----------|-----|
| lie detector | Misrepresents the product |
| detects lies / lie detection | We do not detect lies |
| truth detector / truth machine | Overclaim |
| polygraph / polygraph substitute | Explicitly prohibited use |
| proves deception / confirms lying | Verdict language |
| the subject is lying | Forbidden conclusion |
| guilty / not guilty (as system output) | Legal finding |
| diagnosis (as system output) | Clinical finding |

## Required vocabulary

| Prefer | Avoid |
|--------|--------|
| observation / observes | detection of lies |
| signal / indicator / cue | finding / verdict |
| inconsistency / conflict in testimony | "caught in a lie" |
| officer assist / interview support | automated interrogation |
| probabilistic / confidence-scored | certain / definitive |
| sealed observed indicator | sealed proof of deception |

## Approved one-liners

- CueLiez observes behavioural and linguistic signals and testimony inconsistencies in real time and presents them to the officer as cues.
- CueLiez does not detect lies. It observes actions and patterns around contested accounts so humans can inquire more effectively.
- Aimed at making the interview more meaningful for both the guilty and the innocent.

## Seal and memory language

When describing storage:

- Use **observed indicator**, **grounded observation**, **epistemic_status compatible with observation**
- Never describe sealed packages as legal findings, diagnoses, or confirmed deception

## Review checklist

Before publishing any external text:

- [ ] "Lie detector" (and synonyms above) absent
- [ ] First mention expands Legal Interview Engine
- [ ] Human judgment remains explicit
- [ ] Guilty and innocent framing preserved where purpose is stated
